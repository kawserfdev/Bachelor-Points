# Mess Manager Landing Page

A premium, conversion-focused SaaS landing page for the **Mess Manager** platform. Built with a modern tech stack and "Stripe/Linear" inspired design patterns.

## 🚀 Tech Stack
- **Next.js 15 (App Router)**
- **TypeScript**
- **TailwindCSS 4**
- **Framer Motion** (Animations)
- **ShadCN UI** (Components)
- **Lucide React** (Icons)

## ✨ Key Features
- **Premium Design**: Dark/Light mode support, glassmorphism, and smooth gradients.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Interactive Dashboard Mockup**: A realistic preview of the app's functionality.
- **Structured Content**: Hero, Problem/Solution, Features, How it Works, App Screenshots, Testimonials, FAQ, and Final CTA.
- **Clean Architecture**: Modular component structure organized by `layout` and `sections`.

## 🛠️ Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the site**:
   Go to [http://localhost:3000](http://localhost:3000)

## 📁 Component Breakdown
- `components/layout/`: Global elements like Navbar and Footer.
- `components/sections/`: Individual page sections for easy maintenance.
- `components/ui/`: Atomic UI primitives from shadcn.

## 📝 Design System
The project uses the **Electric Indigo** design system. You can find the full specification in the `design_system.md` artifact.
